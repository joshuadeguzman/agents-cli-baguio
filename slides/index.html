What is an agent?

A model, an instruction and some tools, in a loop.

Instruction

Its job, in plain words. “You are an on-call engineer. Explain what broke.”

Model

Gemini reads the request and decides the next step.

Tools

Plain functions it can call, like read_log and find_errors.

The loop

Call a tool, read the result, then answer or call another one.

One minute. Four presses.

Use the root cause agent from the end of the talk as the example. A chatbot answers from what it knows. An agent goes and looks: it calls find_errors, reads the lines, then answers.

Why write an agent when you already have Claude or Antigravity?

A chat session starts from zero every time. An agent keeps the instructions, tools and checks in code.

90 seconds. Press → twice.

Left: the same weekly task typed into a chat app. You repeat the rules, you phrase them differently, and the answer drifts. In week 38 the rounding and outlier rules weren't in the prompt, so they didn't happen.
Right: the rules live in app/agent.py. Every file goes through the same agent, and eval run tells you when a change breaks it.
Don't knock chat apps. They're the right tool for one-off work. Write an agent when the task repeats, or when something other than you needs to run it.

# example prompt, with the skills installed
Turn app/agent.py into a data analyst for app/data/sales.csv. Write pandas, run it with BuiltInCodeExecutor, and answer with the computed numbers.

BuiltInCodeExecutor runs the code inside Gemini, not on your laptop. It has to be the agent's only tool.

adk.dev/integrations/code-execution google.github.io/agents-cli/guide/development 
async def load_dataset(callback_context):
    state = callback_context.state
    state["dataset_csv"] = DATASET.read_text()

root_agent = Agent(
    name="ask_your_data",
    model=Gemini(model="gemini-3.8-flash"),
    instruction="""Write pandas and run it.
Answer with the computed numbers.
{dataset_csv}""",
    code_executor=BuiltInCodeExecutor(),
    before_agent_callback=load_dataset,
)

app = App(root_agent=root_agent, name="app")

Two minutes

One rule from the eval skill: App(name="app") must match the folder name, or you get "Session not found" errors.

STEP 8Pick metrics that run on your machine

# tests/eval/eval_config.yaml
metrics_to_run:
  - answer_matches_truth
  - custom_response_quality

custom_metrics:
  - name: answer_matches_truth
    custom_function_file: answer_match.py
  - name: custom_response_quality
    custom_function_file: response_quality.py

answer_matches_truth

Python. Checks that the expected numbers appear in the answer. No model call.

custom_response_quality

The scaffold's LLM judge. Scores 1 to 5 using your GEMINI_API_KEY.

Built-in metrics need Google Cloud

final_response_quality, hallucination and safety call the Eval Service in Gemini platform.

google.github.io/agents-cli/guide/evaluation

90 seconds

This is the part people get wrong: custom Python metrics run locally, built-in metrics need a project. The scaffold's default judge is local, so eval run works on an AI Studio key out of the box.
BuiltInCodeExecutor runs inside Gemini, so the code never shows up as a tool call in the trace. That's why we check the numbers in the answer instead.
